# 任务线章节框架（阶段⑤ 设计稿）

> 依据：《整合包开发方案_v4_装备流程改版.md》3.6（任务线四轴）+ 3.3（武器线谱系）+ 3.5（五阶段门控）；共生体数值引用《Symbiote配置调频设计.md》附录（jar 字节码提取的硬编码值，**改不了，只能引用**）。
> 配套门控脚本：`scripts/stages.zs`（stage id 定义与授予命令对照表见该文件末尾）。
> **本文件为大纲设计稿，不进游戏。** FTB Quests 任务数据（SNBT，存放于 `config/ftbquests/`）由游戏内任务编辑器生成，**不要试图手写 SNBT**。

## 0. 全局约定

- **任务类型图例**：[击杀] [提交] [进度] [到达]。
- **奖励总原则（方案 3.6）：材料 > 成品** —— 任务奖励少发成品武器，多发中间产物与素材（`kubejs:tempered_steel_billet` 淬魔钢坯、`kubejs:refined_iron_ingot` 精制铁锭、Boss 掉落材料），把成就感留在锻造环节；成品仅限序章起始武器与各线「大成」节点的一次性标志性奖励。
- **原版零门控**：任务串不覆盖原版装备流程（木/石→铁→钻石→下界合金），干预政策【待定】。
- **阶段授予**：里程碑任务的命令奖励执行 `gamestage add @p <阶段名>`（@p 以完成任务者为中心解析；对照表见 `scripts/stages.zs` 末尾）。
- **多人**：FTB Teams 队伍共享任务进度。
- **ID 纪律**：未入包模组（Spore 等）与未核实 ID 一律标【待核实】，落地前必须 `/ct hand` 或 F3+H 现场核实。
- **任务依赖构成 DAG**：每章末尾的「依赖关系」行即 DAG 节点声明。

## 序章「觉醒」

定位：Epic Fight 基础操作教学 + 起始武器发放（**加成性质，不替代原版合成**——原版装备流程照常可走，方案 3.6）。

**键位教学表**（Default Options 下发的最终键位，`config/defaultoptions/keybindings.txt`，方案 3.9 ①）：

| 按键 | 功能 |
|---|---|
| 鼠标侧键 5（mouse.5） | 切换战斗/建造模式 |
| R | 固有技能 |
| 左 Alt（LAlt） | 闪避 |
| 右键（战斗模式长按） | 格挡 |
| G | 锁定 |
| K | 技能编辑器 |

（共生体键位教学放共生体养成章：改绑后 Y=触须猛拉、I=Living Armor、M=顶端形态、;=Strain Power、'=臂收放，其余 10 键默认，见《阶段③批1_Symbiote实测记录》第 1 节键位表——jar 字节码已确认，Controlling 复核即可。）

**任务串**（一行一条：类型 + 标题 + 一句描述 + 奖励原则）：

- [进度] 换个姿势：切到战斗模式再切回来，感受重心变化。｜奖励：经验（教学任务一律低价值）
- [进度] 第一套连段：战斗模式下打出一次完整的轻重攻击连段。｜奖励：经验
- [进度] 千钧一发：用闪避躲开一次敌对生物的攻击。｜奖励：经验
- [进度] 稳如磐石：格挡吸收一次攻击。｜奖励：经验
- [进度] 目视目标：用 G 锁定一只生物并完成击杀。｜奖励：经验
- [进度] 打开武库：打开 K 技能编辑器浏览技能树（不要求加点）。｜奖励：经验
- [提交] 觉醒之礼：领取起始武器。｜奖励：起始武器（**成品例外**：全包唯一「白送成品」，理由=教学靶；数值对齐铁级参照锚，具体武器【待核实】）
- [击杀] 小试牛刀：用起始武器击杀 5 只敌对生物，验证教学成果。｜奖励：经验 + 精制铁锭少量

**主线里程碑**：「觉醒」收官任务 = 完成以上全部 → 命令奖励 `gamestage add @p stage1_departure`。

**依赖关系**：无前置（进入世界即可开始）；本章收官 → 开启战斗成长章 Ⅰ 与共生体养成章。
