# 规格书：围城改村庄级共享计时 + 村外生成（2026-09-26）

> 执行方：GLM 产初稿 → K3 审改 → 双写副本+test4+仓库 → 进游戏验收。
> 动因（外部评审 P2-16）：当前 siege.js 计时器每玩家独立——多人各自开波、各算各账；
> 且波次以玩家为中心撒点，与决议"村外生成向村庄推进"不符。
> 红线：Rhino 声明规则最终版（HANDOVER 四点八）；ForgeEvents 仅 startup；getUUID 非玩家实体禁用。

## 改动对象

`kubejs/server_scripts/siege.js`（整段重构计时核心，HUD/失守/波次组成保留）

## A. 计时器：玩家级 → 村庄级共享

1. 村庄键：村民质心坐标按 64 格网格量化（`floor(cx/64),floor(cz/64)`），作为村庄身份 key
2. 计时状态从玩家 pd 迁移到**主世界 level 的 persistentData**，键 `svs_siege_v_<gx>_<gz>`，值为 CompoundTag：
   - `remaining`：剩余 tick（冻结语义不变——无玩家在村时不推进）
   - `lastTick`：上次推进的 gameTime
   - `activeUntil`：围城窗口截止 gameTime
   - `cycle` / `defeatDone` / `startVillagers`：同现语义，随村庄走
3. 推进规则：每秒，对每个在线玩家：在村 → 取其村庄 key，若本 tick 未处理过该 key 则
   `remaining -= (gameTime - lastTick)`（多人同村只扣一次），`lastTick = gameTime`；
   不在村 → 不写 lastTick（时间自然冻结，无需操作）
4. 回村回拨（remaining < 5 分钟 → 拉回 5:00 + 预警）改为按村庄 key 判定，预警发给村内全部玩家
5. HUD：玩家看到的倒计时=所在村庄的共享值；暂缓/失守态同现逻辑

## B. 波次生成：玩家中心 → 村外环带

1. 开波时计算村民质心（村庄中心），波次以**质心为圆心** 32~48 格环带 summon+spreadplayers
   （环带在村外，真菌怪 AI 自然向村推进）
2. 触发者 = 该 tick 处理到该 key 时在村的玩家（广播 title 仍以村庄中心 @a[distance=..128]）
3. 失守判定与罚款不变，范围改为村庄质心 128 格

## C. 数据迁移

旧玩家 pd 键（svs_siege_timer/was_in/cycle/active_until/start_villagers/defeat_done）废弃不迁移
（村庄计时从零开始即可，旧键留着无害）；代码里删掉读写即可。

## D. 验收标准

1. `Loaded 7/7 server 0 errors`；日志 `[SVS-围城]` 行带村庄 key（如 `v_12_-8`）
2. 两人同村：倒计时只扣一次（快进命令各设一次，剩余值一致）；一人离村一人留守：照常推进；两人都离村：冻结
3. 快进触发后：怪撒在以村庄质心为圆心的环带（不在玩家脚下）、村内全员收到 title
4. 失守：文明 -15 + 在村者均摊扣款（单村一次）
