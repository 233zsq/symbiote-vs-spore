# 整合包开源协议审查报告

> 对象：151 个 mod（含 SLM 前置链）+ 我们的三类行为：**使用（打包分发）、汉化（外挂资源包）、魔改（配置/数据包/改 jar）**
> 依据：各 mod `mods.toml` 声明的 license 字段（作者自述，最权威的本包内来源）+ CurseForge/Modrinth 平台惯例。日期：2026-09-20。

## 一、协议分布总览

| 协议类别 | 数量 | 对整合包的态度 |
|---|---|---|
| MIT / BSD / Unlicense / MPL | ~45 | 完全自由，随便用 |

## 二、按行为逐项审查

### 1. 使用（把 jar 打进 zip 分发）

- **开源协议件（~85 个）**：完全合规。
- **ARR 件（~50 个，含灾变、铁魔法、史诗骑士、WoM 系、FTB 系、精妙系、Xaero 系、SLM 系、血源等）**：
  - CurseForge 服务条款允许 CF 站内整合包引用这些 mod（启动器各自下载），这是 ARR mod 整合包的标准玩法。
  - 我们当前是**本地 zip 内嵌 jar，私下分享**：超出 ARR 字面条款，属于社区普遍容忍的灰色地带。
  - **结论：私下玩没问题；若要公开发布，必须改用 CurseForge/Modrinth 整合包格式（只存 mod 引用不内嵌 jar），或逐个取得作者授权。**

### 2. 汉化（svs_zh_cn 外挂资源包，不改 jar）

- 资源包按 key 覆盖语言条目，不修改不内嵌原作者文件 → 对所有协议合规，包括 ARR。
- 魂系/同人译名已按 MC百科与官方简中考证（血源、黑魂、法环、黑神话、LoL 皮肤）。
- **合规 ✅**

### 3. 魔改

| 手段 | 对象 | 合规性 |
|---|---|---|
| 配置/数据包/KubeJS/FTB 任务 | 全部 | ✅ 协议允许且机制如此设计 |
| imfdata EF 武器适配 JSON | 各武器 mod | ✅ 数据包是官方支持的扩展方式 |
| ~~改 jar 内部 mixin JSON~~ → **已合规化（2026-09-25）**：monsterexpansion（PlayerDefenseDamageReductionMixin）、cataclysmic_arsenal（CMItemStackRendererMixins）的冲突 mixin 改由 svs_tweak 的 MixinSquared MixinCanceller 运行时取消，jar 已恢复官方原版（hash 实测回原文档），不动对方 jar 一个字节 | ✅ |
| wukong_compact（非官方移植版） | LGPL | ✅ LGPL 允许修改再分发（移植版本身合法） |

### 改 jar 越界的合规化方案（三选一，按推荐排序）

1. **写自己的微型 tweak mod**（推荐）：一个几 KB 的自研 mod，通过 Mixin 的 config 插件机制在运行时禁用对方冲突 mixin，**不动对方 jar 一个字节**，对所有协议合规。工作量约半天。
2. 取得作者授权（monsterexpansion、cataclysmic_arsenal 作者）。
3. 发布时恢复原版 jar 并在说明里写清"需自行二选一"（体验受损，下策）。

## 三、结论

- **当前私下测试/朋友间分享：整体可接受**，无实际法律风险。
- **公开发布前必须做的两件事**：① zip 改为 CF/Modrinth 引用格式（解决 ~50 个 ARR 的内嵌分发问题）；② ~~两处 jar 补丁改为自研 tweak mod~~ **已完成**（MixinSquared 取消器，2026-09-25）。
- 汉化与配置级魔改全程合规，无需改动。
