## 四、⭐ 线性结构主线设计提案（任务线重写的结构输入）

四阶段结构序列——玩家被任务/交易线索/指南针逐段引导，淡化档的探索结构只作背景偶遇：

```
Ⅰ 启程（村庄立足）
  出生小屋(roadweaver) → 阡陌路网导流 → 原版/jerotes 村庄【村庄据点：交易·火种·指南针】

  →【里程碑：共生】围城教学 + inqui:tower 首见（真菌威胁登场）

Ⅱ 磨砺（日课 + 定点讨伐）
  ★colosseum_arena（单体日课：技能书/饰品）↔ ★sky_arena/ice_arena（对群日课：币/材料）
  → ★inqui:tower → underground → entrance（SI 定点讨伐三连，奖真菌之魂+线索）
  → saintsdragons 栖巢（淡化偶遇：驯龙支线）
  →【里程碑：二轮制霸】jerotes 二轮维度（维度内结构线）

Ⅲ 天灾防线（真菌 + 灾变双主线推进）
  真菌线：★spore:military_camp（前线）→ ★prison → ★hospital → ★lab（起源）
          → ★cathedral（大本营）→ ★inqui:arena（审判场 Boss）
  灾变线：★soul_black_smith（首站·装备铺垫）→ ★burning_arena → ★ruined_citadel
          → ★cursed_pyramid → ★sunken_city → ★frosted_prison → ★ancient_factory
          → ★acropolis（灾变终章）
  （两条线可并行/交叉，任务线决定推进顺序）

Ⅳ 反推（终局）
  母巢波次事件（非结构）→ 终局 Boss → 末期武器任务线直发（已裁决）
```

## 五、当前使用边界

结构取舍已按10-03裁决收敛，不再安排“重建1.0.5”或重复拍板。主线推进顺序仍由后续设计稿批准；原版政策待定、worldgen冻结，不能据旧spacing和线性示意图安排新生成改动。
