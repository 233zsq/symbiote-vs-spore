## 一、机制决议（已拍板）

### 1. 真菌围城
- 7 天一周期，真菌怪潮冲村庄，向村庄中心推进
- 倒计时只在玩家位于村庄区域（128 格）时走动；离村/跨维度冻结（HUD 显示"围城暂缓"）
- 长离村>60秒后回村且余时不足5分钟 → 回拨5:00并预警；短离村≤60秒不回拨（执行状态M1.1：两子项待测）
- 怪在玩家附近自然加载区块内生成，**不强加载**（避免强加载成本；脚本/怪物负载仍需实测）
- HUD 天数计时器：KubeJS 客户端绘制，"第 X 天 / 距围城 N 天"，围城日红色预警

### 2. 火种绑定系统
- 绑定村民=火种；工具任务发放 + 真菌币补购；上限约 5 个
- 绑定后直接给该村民当前等级最贵的可交易物品
- 挂**文礼 civillis**的文明强度评分（每火种 +N 分/死亡 -M 分），喂给它的城镇中心等级系统——绑定人数越多村庄文明级别越高
- 配套：Human Era 材质包（ETF+EMF 前置，拟人化村民外观）+ Guard Villagers（卫兵，配 EF 附属让卫兵有招式）

### 3. 真菌残魂经济
- KubeJS物品真菌残魂（id `kubejs:spore_coin` 不变） + 自定义村民交易，不加货币 mod
- 打怪掉落、悬赏/日课奖励；用于买匠魂材料、匠魂升级、绑定工具

### 4. 难度体系
- 三档进游戏内：FTB 序章任务自选，奖励表执行命令（简单 0.6×攻 0.8×血 / 普通 1×/1× / 困难 2×攻 1.5×血 + Boss 掉落更肥）
- 脚本层限伤全部删除（10-01裁决），灾变原生cap实证已无上限；不恢复母巢8%/减伤爬升模板。
- 远程方向结算：玩家被弹射物打×0.5；玩家打飞行/水中怪×2、地面Boss归零、地面小怪×0.5；怪内战不动。精确名单与归因边界见HANDOVER四/五。
- 飞天/水下怪物加强远程伤害；匠魂升级可购买

### 5. 多人惩罚（钱罚个人、文明罚集体、递减防归零）
- 火种死亡：扣绑定者真菌币；绑定者不在线 → 村庄文明等级小幅下降
- 围城失守：文明等级降一级 + 在场玩家均摊扣款（单人全额）
- 连续火种死亡惩罚递减（第二次 50%、第三次 25%）
- 绑定者 7 天未上线火种自动解绑（文明不降级）

### 6. 结构设计
- 密度提纯：75 格半径最多 1 个结构，白名单放行主线结构、黑名单删垃圾结构（远梦之棺方案）
- 关键结构（共生体陨石）：自研 tweak mod 做距出生点生成限制；其余结构用密度+引导
- 结构寻找：阡陌交通（修地图结构名汉化）+ 探险家指南针 + 自然指南针 + 圣龙坐骑侦察
- 下界/末地**不做门禁**，任务引导自然推进

### 7. 末期武器直发
- Gateways/Placebo与武器解锁制已否决；末期武器由任务线直发，具体奖励随后续设计稿批准。

### 8. 铁魔法弱化
- 只保留 buff 系 + 武器附魔远程系，EF 辅助定位
- 删禁强控制/强回复法术（止心术等，清单已定稿：铁魔法禁用清单.md（禁78/留36））
- 剑术耗蓝开启 + 冷却 2 倍

### 9. 匠魂定位：保底成长线/逃课辅助
- 炉子开局送、材料可买、打 Boss 补材料
- 自定义材料强度天花板压在 Boss 掉落武器之下——高手打 Boss 拿神兵，手残刷材料堆保底刀

### 10. 共生体 × EF 适配（分期）
- 分期 1（零开发）：共生体进化阶段挂 GameStages 数值加成（穿甲/韧性/回复）
- 分期 2（自研附属 mod，初版后做）：触手辅助战——持械自动攻击（对 Boss 削至 20% 以下）、自动格挡/闪避（概率触发随进化阶段提升）

### 11. 结局
- 反推真菌成功 → 开放世界继续（Boss 可重生/日课继续）；NG+ 二期再议

## 五、共生体克制真菌（2026-09-23 晚讨论定稿）

### 共生体原生机制（开包实证）

- **结合阶段（BondStage）4 级**：ATTACHED 附着 → INTEGRATED 整合 → COOPERATIVE 合作 → DOMINANT 主导（可退化）
- **状态数值**：Bond 结合度 / Trust 信赖 / Stress 压力 / Hunger 饥饿 / Stamina 耐力 / Armor / Tension
- **五种类型（Strain）**：猎手（追猎进食）/守护者（格挡）/暗影（夜行）/循声（索敌）/皇家（最强但失控风险）
- **原生狩猎状态**（PredatorHunt/SymbioteFeedingHunt）、触手系统（SymbioteArmsController）、失控惩罚（保留原样）

### 克制真菌设计（分期 1，KubeJS 落地）

1. **伤害克制**：共生体玩家对真菌（spore 命名空间）伤害按结合阶段乘系数：附着 ×1.1 → 整合 ×1.2 → 合作 ×1.35 → 主导 ×1.5；受真菌伤害减免 10% → 15% → 22% → 30%
2. **狩猎红利**（狩猎状态击杀真菌，**高于狩猎普通生物**）：
   - 真菌小怪：饥饿 +3 / 耐力 +8 / 信赖 +3
   - 真菌精英：饥饿 +6 / 耐力 +20 / 信赖 +8
   - 真菌 Boss：饥饿与耐力全满 / 信赖 +25
   - （数值为初版默认，实测后微调）
3. **失控保留原样**，且**围城日压力上涨更快**（围城与共生体失控联动）
4. **反向仇恨**：真菌怪优先攻击共生体玩家（天敌感应，奖励与风险对称）
5. **类型路线**：融合时全随机（看结构生成的共生体类型，看命）
6. 共生体触手辅助战（持械攻击/自动格挡/自动闪避）仍为分期 2 自研附属，参考 Symbiotes Unleashed 的物理触手实现

### 共生体其他 mod 评估（不进包）

- Ultimate Symbiote（RPGEmperor）：漫威毒液主题，气质不符，不加
- Symbiotes Unleashed（Sev Champion，0.1.x beta）：独立新共生体 mod，不换核不共存，仅作分期 2 参考书
