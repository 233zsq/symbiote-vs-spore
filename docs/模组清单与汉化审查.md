### C. 硬编码 / 无法通过语言文件汉化的模组

| 模组 | 情况 | 结论 |
|---|---|---|
| ash_of_sin | 仅 3 个 class，配置项标签硬编码在字节码里，游戏内无 UI | **硬编码**。仅配置文件注释为英文，不影响游玩，不改 |
| multiplayer_boss_fight | 硬编码字符串全是日志输出 | 无玩家可见文本，无需汉化 |
| epic_fight_avalon | 仅开发环境提示 | 无玩家可见文本，无需汉化 |
| EFMCompat | 纯 JSON 数据包，无 lang | 无字符串，无需汉化 |
| spore_inquisition | 纯数据包（bettercombat 属性等） | 无字符串，无需汉化 |
| appleskin | 官方 jar 即不含 lang 文件，tooltip 走硬编码 | **硬编码**。仅有少量悬停提示英文，影响小，不改 |
| ambientsounds | jar 无 lang，配置界面字符串走 CreativeCore 体系 | **硬编码嫌疑**。配置菜单英文，影响小，不改 |
| chunky / mousetweaks / packetfixer 等性能件 | 无 lang 或仅命令反馈 | 玩家基本不可见，不改 |

### D. 汉化不了/不做的最终清单

ash_of_sin（硬编码配置串）、appleskin（硬编码 tooltip）、ambientsounds（硬编码配置界面）。
其余 EN=0 模组经核实为无玩家可见文本（纯库/数据包/后台件），不属于"汉化不了"，而是"无内容可译"。
