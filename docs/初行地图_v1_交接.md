1. 阅读本文件与 [地图制作说明](../maps/first-light-v1/README.md)，区分已验证内容和客户端待验项。

## 5. 技术问题与工具使用注意

- **结构生成与导航分开验。** 原版 `/place structure` 不自动持久登记 StructureStart。当前以道路和路标导航，不能从建筑存在推断 `/locate`、Explorer's Compass、结构范围刷怪或任务检测正常。
- **道路检查只证明保存了铺装。** 当前脚本检查中心坐标附近 Y±2 范围的路面，不保证坡度、头顶空间、栈道护栏、支柱或整段入口都适合玩家行走。三维路线验收见下一节。
- 首次检查发现家具覆盖四个床方块部分、337 个道路采样点因砂砾落水缺失。已移开家具，低处改为 Y≥64 的木质栈道并加支柱，陆地改为夯土，终检缺失归零；修正已回填生成器。
- 最小组合未包含 Spore Inquisition。其首次加载出现对组合外实体/命令的函数引用，移除后重新创建了干净世界。Spore 原 JAR 的 Create / Farmer's Delight 等可选联动配方仍有加载错误，不能把当前启动成功称为零错误或完整玩法兼容。
- RoadWeaver 内嵌 OpenCL 模块依赖 LWJGL 核心库；独立服务端已补入官方 `lwjgl-3.3.1.jar` 并调整模块路径。制图配置关闭 `performance.openclCoarseSamplingEnabled`，使用 CPU；模组 JAR 本体未改。
- 主包 packwiz 索引哈希不一致另见来源核查第 5 节，尚未处理。当前独立 mrpack 使用自己生成的标准索引，其打包通过不能代表主包索引已修复。
