# 武器线 + 匠魂节奏 · 四参考包拆包综合（2026-09-29）

> 来源：四代理并行拆包（CTI / 沉浸战斗 4.2.9 / 终焉决斗 / 远梦之棺，FTB 任务 SNBT + kubejs 实证）。
> 用途：任务线重写（用户裁决"全部重写"）与武器发展线路设计。本文档只出分析和建议，最终方案用户拍板。
> 本轮（第二遍）补：**CTI 的装备/饰品解锁设置**、**护甲/饰品/EF 技能书三轴的横向对比**，并订正三处旧结论。

## 〇、订正三处（第二遍实证复核）

1. **沉浸战斗的"武器列表章/套装盔甲/猎人腰带"是任务节点，不是章节** —— 章标题要从章节文件自身的 `title:` 取（别被 quest 节点的 `title:` 干扰）。IF 真实章节是：道具列表组（派生树 / 实用物品 / **装备外观** / **武器列表** / 坐骑）+ 物品兑换组（**饰品兑换** / **技能书兑换** / 召唤挑战）。
2. **远梦之棺没有"技能章"**：`{skill.epicfight.guard}` 是**基础武器章（ji_chu_wu_qi）首个任务的 subtitle**，不是章标题（四种基础技能书排成 y=10 一排）。
3. **CTI 钴/阿迪特熔点 950°（岩浆 1000° 就够）** —— 下界章节是**任务订单门槛**（要求提交 raw_cobalt+raw_ardite），不是温度门槛。真正的烈焰血（1500°）门槛从**玛玉灵 1200 / 女王史莱姆 1150 / 黑青铜 1400** 开始。

## 一、CTI：匠魂材料怎么分阶段

**CTI 没有阶段门控 mod**——门控全靠软机制三条：任务书引导（提交式订单）+ 燃料温度阶梯 + 维度/科技进度。

- **炉子半送半做**：送工作站/部件台/64 模具/装好熔岩的燃料容器/32 焦黑砖；熔化炉本体、浇筑口、冶炼炉控制器自己合。另有世界结构"焦黑小屋"白捡起步物资
- **材料五层**（第二遍精确化）：

| 层 | 温度/门槛 | 材料 | 门控方式 |
|---|---|---|---|
| 手搓层 | — | 石/木/燧石 | 开局即做 |
| 熔岩层 | ≤1000° | 铁铜金 → 工匠青铜/玫瑰金(550)/生铁(811)/紫晶青铜(820) | 冶炼炉本体自合 |
| **下界订单层** | **熔点 950，岩浆即可** | **钴 / 阿迪特** | **任务要求提交**（第 0 章"深入下界"偷烈焰人笼订单）——不是温度锁 |
| 烈焰血层 | ~1500°（烈焰血燃料） | 女王史莱姆(1150)/玛玉灵(1200)/黑青铜(1400) | 燃料温度真锁（`tinker_fuels.js` 五档 2000/3500/5000/7000/9500） |
| 毕业层 | 科技链 | 中子素（核电）→ `cti:stellar_manyullyn` 星河玛玉灵（无尽工作台） | 维度/科技进度 |

- **图鉴收集册**：材料册按等级-章节映射（"第一章 1~5 级、第二章 5~7、第三章 7~9、无尽 10、贡献者 14"），每材料"提交→赏金"，**纯激励不门控**
- 关键证据：`kubejs/server_scripts/tinker_fuels.js:3-46,48-65`；`chapters/mainchapter0.snbt:862-930,1812-1987`；`18CB42585E1E256C.snbt:12-16`

### 1.1 CTI 的"装备/饰品解锁设置"（本轮新增——用户特别问的）

结论：**CTI 的装备与饰品也一律不做配方/阶段锁，全靠"任务送成品 + 图鉴收集 + 玩家自选"**。

- **开局直接送半套甲**：序章首个任务奖励里就有 `tconstruct:pickaxe`（display"角落里的矿工镐"）+ `makeshift_helmet/chestplate` + `laminar_leggings/boots`（`mainchapter0.snbt:446-610`）
- **匠魂护甲**：`travelers_*` 全目录未查到；收录的是**镶板护甲**与**层板护甲（laminar）**，归"工具大全"章，该章 **0 条 dependencies**、`match_nbt:false`（只验部位/材质不限）→ **开放式图鉴，无依赖链门控**
- **饰品**：`curiocollection.snbt` 是个 **246 种饰品的大图鉴**（族内 25 条小依赖、全章仅 5 处 rewards → 纯激励）；神秘遗物专章自述"任何时期都可以尝试发展，因此位于特殊章"（**明确拒绝阶段门控**）；天境饰品另走独立槽系统
- **替代门控的三招**（可抄）：① 开局送成品 ② 章末/流程节点送机器与料（例：合金离心机返 9×熔融玫瑰金；中子矿任务返 8×中子素锭）③ 图鉴收集给赏金

## 二、沉浸战斗：武器分类 = 类型分列 + 毕业奖励

- 武器集中"道具列表"组：**武器列表章按武器类型成列铺开**（simplyswords 双列 / efn / 奇迹 / celestisynth），每把一收集任务
- **每类型末尾挂毕业奖励**（x=9.1 竖排 9 个八角节点）：集齐该类型全套 → 送**可成长武器**（"刷怪升级、每级 +0.1 攻击、最高 50 级"）。九类：长枪=痛苦 / 巨斧=折磨 / 长剑=毁灭 / 大剑=太阳 / 武士刀=杀戮 / 镰刀=神陨 / 单手剑=主宰 / 双持=碎影 / 双头剑战刃=月蚀
- 排行**氛围化**：类别色码 `&b` + 毕业标题 `&c`，**没有强度榜**；阶段定位写在说明文本（"简易刀剑：前-中-后期"）
- 另有**派生树章**（逐级合成链，中间节点奖镶嵌材料 `runefused_gem/netherfused_gem`）

### 2.1 护甲（本轮补充）

**章节 = "装备外观"章**（order=2）：幻化教学 + 按 mod 并列整套收集（fantasy_armor / d&c / souls_like_armors 等）。
根节点「套装盔甲」是纯 checkmark（"全套装备拥有套装效果"，奖 1 xp），下挂**两条逐级依赖路线**：`抗性路线`、`力量路线`，每节点收齐四件套 → **无毕业奖励**。

### 2.2 饰品（本轮补充）

- **饰品兑换章 = 0 依赖的平铺商店**，全部 `can_repeat`，货币是 `paper_ring_low/high` **券**，按功能分区（腰带/披风/靴 / 戒指阵）
- 例：`relics:hunter_belt`（猎人腰带）价 3×高级券，描述"1. 增加护符栏位 2. 提高宠物伤害"
- **栏位扩张不是商品，是 Boss 掉落**：`/curios add ring|hands|charm` 挂在 BOSS 清单章的特定 Boss 上
- 饰品 mod：curios / RingsOfAscension / relics / curiouslanterns / 自研；**只按功能 + 券档（2~5 张）定价，无阶段/强度分类**

### 2.3 EF 技能书（本轮新增——用户特别问的）

**有专门一章：「技能书兑换」（order=1）**，全部可重复兑换：任务给资源、奖励 `epicfight:skillbook{skill:...}`。
- **价档就是隐性分级**：基础翻滚/跨步仅 16 铁锭（还一发两本：`epicfight:roll`+`efn:efn_dodge`）；"看破"要 64 绿宝石+64 金锭+5 高级券
- 分类只靠**背景图 hover** 标「(防御类)」「(增伤类)」；**无排行**
- **发放渠道**：NPC 兑换（怪物猎人给技能书券/渔夫给饰品券）、传送门挑战、战利品袋；技能书本体还作为收集任务出现在武器列表章（`efn:hf_murasama→zansetsu` 这类武器专属书）
- 教学放基础教学章（"右键技能书打开学习、按 J 管理"）

### 2.4 引导页的流程建议（原文要点，最有参考价值）

- 总纲："**先制作实用道具页面的基础功能物品，完成盔甲升级路线以及几个成品武器，再进行武器收集**"
- 护甲："铁套、钻石套仅为初期装备，尽快提升；套装效果护甲分**力量/抗性/急迫**三类"
- 武器："前中期以制作成品武器（简易刀剑类）为目标、建议同时做多把；中后期伴随 BOSS 素材制作夜幕/奇迹/天神造物"

## 三、终焉决斗：分类 = 类目节点 or 枚举，排行 = 依赖链 + 氛围

- **每个武器类型一个"类目任务"**：用 `itemfilters:or` 把全系列按强度从低到高枚举（木→石→铁→钻→下界合金→模组武器），任得其一解锁该类目——免维护
- **具体武器挂类目下游**：同一条依赖链 = 升级路线（血瞳→血瞳·凋零浸染→血瞳·魔龙深渊），**依赖深度本身就是排行**
- **排行氛围化**：标题颜色码（金/紫/蓝/红=名刀）+ 副标题点评（"前期第二高性价比武器""前公认轮椅武器""理论单次伤害之上限"），拒绝硬 Tier 表
- **尖兵利刃章（63 任务）**：中心枢纽 checkmark → 按类型分列 9 个锚点（对剑/太刀/斧/打刀/长枪/长剑/双匕/大剑/护手，各含一个 `itemfilters:or`）→ **y 轴 = 强度梯度**（8.5 → 16.5 → 25.5 → 33.5 顶档带底板图）；**没有全章集齐式毕业奖**
- 奖励统一 xp 常数

### 3.1 护甲（本轮深挖「盔甲饰品」章）

**分类维度 = 套装，不是部位**，y 轴分层即"阶段带"：
- y≥0 原版材质链（皮革 2.5 / 铁 -2.5 / 锁链 2.5 / 金 5 / 钻石 0）→ 下界合金 y-6 → 模组套 y-9~-12.75（焰魔/腐金/白泣/死亡骑士/圣尊/金龙，六边形）→ **y-15.75/-16.5 是最底的饰品节点（八边形）**
- 中心是 checkmark「套装效果！」（"部分原版套装任意两件即得半套增益"），全章依赖它
- **依赖链即阶段排行，但作者刻意淡化**：钻石套 desc 写"所有分化盔甲套装的起点"；死亡骑士套明写"**放中间只是为了任务好看，不代表实际强度，请根据获取难度和阶段自行判断**"
- **饰品挂在顶级套下游**（5 个无标题节点）：deathskull←死亡骑士 / wtamulet←白泣 / ignisheart←焰魔 / goldendragonclaw←金龙 / paragoncrown←圣尊

### 3.2 饰品（本轮补充）

装了 curios / RingsOfAscension / artifacts / baubley-heart-canisters / curioofundying，但**任务层饰品节点极少、无独立阶段门槛**：
- 序章「饰品大融合」规定"除部分饰品禁用，所有饰品都需要晶簇在**宝石锻造炉**内合成"
- 星际商人：可重复回收戒指（`itemfilters:tag→curios:ring`，注"禁用亡灵戒指"）
- 炼狱决斗场："击杀 boss 掉落，在宝石锻造炉里熔炼成珍贵饰品"；戒指也直接当奖励发（`ring_health`/`ring_poison_resistance`）

### 3.3 EF 技能书（本轮新增）——**四包里做得最细的一章**

**「强身健体」章（33 任务）= EF 技能书主指南**：
- 开篇即定规矩：**"标题为红色是必带技能书，橙色为推荐带"** → 这就是"分类排行"的答案：**用颜色表达优先级，不做数值表**
- 分 5 类各一本一任务，写明功能 + 获取方式：**被动 9 本（最多带 3）/ 闪避 3 / 防御 3 / 行动 3 / 属性 3**
- 红色必带 = 技巧大师/招架/二段跳·踩踏/识破；橙色推荐 = 剑圣/紧急逃生/狂战士/耐力
- **获取途径 = 村民职业一一对应**（盔甲匠←紧急逃生、屠夫←狂战士、制图师←瞬步、农民←超强活力、渔夫←耐力掠夺者、皮匠←技巧大师、图书管理员←翻滚、石匠←招架、工具匠←冲击防御、武器匠←剑圣）；禁忌之力用灵魂之星合成
- 序章直接发初始四本（`step/guard/parrying/technician`）+ 可重复任务换书
- **竞技场三章（终焉/炼狱/圣堂）技能书 = 0**：技能书与 Boss/日课完全解耦
- 另有两张 reward_table（招架/翻滚）**定义了却没被任何章节引用**（闲置）——写任务线时留意别留孤儿

## 四、远梦之棺：图鉴收集册 + 获取途径分带

- 每章一个**隐形总闸**（`invisible:true` 的 advancement 任务，拿到"百兵图"类道具才解锁全章），配 `hide_quest_until_deps_visible`
- 武器章（`wu_qi`，71 任务）内部按**获取途径分带**（y 轴分层）：闸 8.75 → wom/弓/爪 5.25 → Golem 之眼收集 3.0 → efn 结构 0.75 → **技能书交易 -0.75/-1** → Boss 掉落 -2~-8 → **轮回 Boss 解放 -11** → 终极交易 -13~-19
- 单武器任务 = 提交点亮图鉴 → 领通用货币（月结晶）
- "击败人形 Boss 解放武器全部力量" = 轮回章里的武器解锁制（= 被我们否掉的 Gateways 解锁制的原版实现）

### 4.1 装备章（`zhuang_bei`，本轮补充）

**结构 = 隐形闸 + 按 mod/套装三条横带，无依赖深度、无排行文案**：fantasy_armor 三组（同部位全收集）/ cataclysm 四套（返月结晶）/ mowziesmobs 面具+地卜师袍；11 个任务全部直连闸。
奖励梯度是唯一的"排行"：整组=100 经验级、单套=月结晶。

### 4.2 饰品（本轮补充）

**无独立饰品章，走"票据制"**：`zhong_yao_wu_pin`（重要物品章）里放两张**隐形**票据任务（`artifact_ticket` / `rare_artifact_ticket`），Boss（神魔章）掉高级票据 → 文案"可在[圣殿港口]的[摆渡人]处提炼饰品"。另有装备当维度钥匙（`cataclysm:necklace_of_the_desert` 带 dimension task）。

### 4.3 EF 技能书（本轮订正 + 补充）

全包 skillbook 任务仅 6 处、**都不发放**（都是"要求你拥有"）：
- **基础武器章 y=10 一排四本**：`epicfight:guard` / `efn:efn_parry` / `efn:efn_dodge` / `efn:efn_step`，全部 `only_from_crafting:true` → **必须自己合成**，subtitle 即技能名（防守/招架/类魂闪避/类魂跨步）
- 武器章两本（`efn:zansetsu` 高频村雨专用、`efn:mortal_blade`）挂"终极交易带"
- **无强度分级**，差异只在来源（合成 vs 交易）与武器绑定
- **技能成长走另一条腿**：神魔章 21 个击杀任务奖 `epicskills:ability_stone`（技能点），配 `epicfight-skilltree`

## 六、对 SvS 的建议方案（扩展版，待你拍板）

**武器章结构（融合 DOTE + 远梦 + IF 毕业奖）**：
1. 类目节点用 DOTE 式 `itemfilters:or` 枚举（免维护）
