# 武器线 + 匠魂节奏 · 四参考包拆包综合（2026-09-29）

> 来源：四个子代理并行拆包（CTI / 沉浸战斗 4.2.9 / 终焉决斗 / 远梦之棺，FTB 任务 SNBT 实证）。
> 用途：任务线重写（用户裁决"全部重写"）与武器发展线路设计。本文档只出分析和建议，最终方案用户拍板。

## 一、CTI：匠魂材料怎么分阶段

**CTI 没有阶段门控 mod**——门控全靠软机制三条：任务书引导 + 燃料温度阶梯 + 维度/科技进度。

- **炉子半送半做**：送工作站/部件台/64 模具/装好熔岩的燃料容器/32 焦黑砖；熔化炉本体、浇筑口、冶炼炉控制器自己合。另有世界结构"焦黑小屋"白捡起步物资
- **材料五层**：手搓层（石木燧石，开局即做）→ 熔岩层 ≤1000°（铁铜金→工匠青铜）→ 烈焰血层 ~1500°（第 0 章强制下界偷烈焰人笼，解锁钴/阿迪特）→ 科技燃料层（2000°~9500° 自定义燃料，走 IE→PnC→Mek→无尽科技链）→ 毕业层（中子素）
- **图鉴收集册**：材料收集章按 mod 分组，"半身/全收集"奖励，纯激励不门控
- 关键证据：`tinker_fuels.js` 五级燃料阶梯；`mainchapter0.snbt` 起步赠送链

**对 SvS 的可移植性**（我们没有 IE/Mek 科技链）：燃料温度门用不了那么多层，但可简化成三段：
熔岩（主世界）→ 烈焰血（下界，中期门）→ 毕业级高温燃料（末期）。送起步那套直接抄（我们理念 10 本来就"炉子开局送"）。

## 二、沉浸战斗：武器分类 = 类型分列 + 毕业奖励

- 武器集中"道具列表"组：**武器列表章按武器类型成列铺开**（长枪/长剑/武士刀/大剑/巨斧/镰刀…），每把一个收集任务
- 每类型末尾挂**毕业奖励**（收集齐该类型全套 → 送可成长武器"刷怪升级每级 +0.1 攻"）
- 阶段定位写在**说明文本**里（"简易刀剑：前-中-后期"），不做数值榜
- 另有**派生树章**（合成进阶线，中间节点送镶嵌材料）和品质抽奖系统（词条与强度解耦）

## 三、终焉决斗：分类 = 类目节点 or 枚举，排行 = 依赖链 + 氛围

- **每个武器类型一个"类目任务"**：用 `itemfilters:or` 把全系列按强度从低到高枚举（木→石→铁→钻→下界合金→模组武器），任得其一解锁该类目——免维护
- **具体武器挂类目下游**：同一条依赖链 = 该武器升级路线（血瞳→血瞳·凋零浸染→…），依赖深度本身就是排行
- **排行氛围化**：标题颜色码（金/紫/蓝/红=名刀）+ 副标题点评（"前期第二高性价比""前公认轮椅"），拒绝硬 Tier 表
- 奖励统一 xp 常数，简化平衡
- 盔甲按材质链逐级依赖（皮革→…→下界合金→模组套装）

## 四、远梦之棺：图鉴收集册 + 获取途径分带

- 每章一个**隐形总闸**（拿"百兵图"道具才解锁全章），`hide_quest_until_deps_visible`
- 武器章内部按**获取途径分带**（版面 y 坐标分层）：Boss 掉落锻造带 / Golem 之眼收集链带 / 结构 loot 箱带 / 轮回 Boss 解放带 / 终极交易带
- 单武器任务 = 提交点亮图鉴 → 领通用货币（月结晶）
- "击败人形 Boss 解放武器全部力量"——就是被我们否掉的 Gateways 解锁制的远梦原版实现（轮回章）

## 五、对 SvS 的建议方案（待你拍板）

**任务线武器章结构（推荐融合 DOTE + 远梦）**：
1. 类目节点用 DOTE 式 `itemfilters:or` 枚举（省心免维护）
2. 排行用 DOTE 式"颜色+点评副标题"（氛围化，不做数值表）
3. 版面分带用远梦式"按获取途径分层"：交易可买带 / 匠魂保底带 / Boss 掉落带 / 毕业带
4. 奖励：统一真菌之魂（我们的月结晶位）+ 经验；毕业节点发一次性标志性成品

**匠魂节奏（推荐 CTI 简化三段）**：
- 前期：任务送炉子起步件（半送半做）→ 熔岩层
- 中期：下界烈焰血层（钴/阿迪特）
- 后期：毕业材料压在 Boss 掉落武器之下（理念 10 红线不变）
- 图鉴收集册可做可不做（做了是后期填充内容）

**与四阶段对齐**：Ⅰ 交易+原版 → Ⅱ 匠魂起步+竞技场奖技能书 → Ⅲ 灾变掉落神兵 → Ⅳ 毕业直发（任务线）。
