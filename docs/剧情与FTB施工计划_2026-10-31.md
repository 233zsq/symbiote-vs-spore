# 剧情与FTB施工计划

更新：2026-10-31。用户批准先合入本批模组、整理资料，再制定剧情／FTB施工计划；本轮止于计划交付，没有继续生成或替换任务。地图、史诗战斗适配及整合包其他工程由相应对话负责，不包含在本计划的施工授权里。

## 1. 当前基线、目标与工作边界

叙事继续以《天外成王篇》v4与旧世四传说v5增补为基线：玩家与共生体以征伐、军工和进化登顶，母巢战役与大圣身份不降格。具体玩法兑现须有实现证据，文案不能直接变成天基、劫火或金身功能。

当前任务源仍为`docs/questbook_v2.json`，文件名虽旧，内容修订为`6.1-legendarybosses-20261018`。本轮只读检查为21章、2491个任务定义、8个pending；这些是生成源定义数量，不是已验收任务数量。生成器`--check`可验证当前源与生成结果，不运行旧`rewrite_questbook_v6.py`重建覆盖。

test仍是已安装的v6任务，母本任务与仓库v6.1存在既有差异；本轮安装新模组没有同步任务，也没有顺带安装Legendary Bosses。因此后续先做三处差异和进度迁移设计，再安装新的剧情／任务批次，不能把仓库存在的LB节点当成玩家已能进行的战斗。

交付目标是“玩家按需要逐步看到目标，知道为什么出征，完成支线后获得有用增援，战后能看到下一步”。任务数量不作为目标。所有阶段使用“目标→准备→步骤→产出物→验证”的固定骨架，只排优先级与依赖，不排具体日期。

## 4. 后续写作、显示、美术与奖励标准

每个主线节点先回答五件事：为什么现在去、怎样找到目标、实际做什么、怎样判定成功、战果在下一段有什么用。详细机制放详情，节点标题与首屏保持简洁；不把战斗情报写成没有依据的攻略。

显示采用依赖逐步开放，玩家正常模式只看到当前行动、近期分支与必要预告。武库继续分批展开，允许主动翻下一批，不强迫先全收齐。验收须退出编辑模式；编辑模式显示隐藏节点不能作为逐步解锁失效的证据。

Boss节点使用真实正面来源缩为16×16并加深色描边，必要时人工修细节；武器、护甲和材料用对应物品模型。不得拿UV图册当脸、用无关材料代指Boss，或把旋转模型默认塞满所有小图标。Quest Enhance实体模型优先放详情页，样章确认后再扩展。缺少合格头像时标“缺来源”，不冒充完成。

奖励分四路：主线关键补给、军械分档赏格、专精能力／技能书机会、可选挑战饰品与稀有战利品。对每笔奖励登记个人／队伍、首次／重复、数量、用途、重领保护与替代项。保留原生战场掉落的意义，不由任务再次复制同一Boss独有装备。已学技能给替代收益，不自动学全套技能或改EF槽位。

本轮采纳DeepSeek的轻量DND方向为后续设计上限：等级成长／GameStages、加点、少量子职业能力；不移植13职业／44子职业体系，不新增Origins、Apotheosis、TravelOptics。现有四专精继续保留。等级门的具体数值和加点预算在独立规格中确定，本轮不实现、不锁下界／末地、不恢复已否决的通用武器门禁。

## 5. 依赖接口与未决事项

地图／EF交付由各自对话负责。本计划只接收可追溯信息：实体／物品ID、自然或受控取得方式、场地与起战条件、最终判胜、适配状态与证据等级、已知限制、来源路径／修订。坐标、seed、模型、动作和数值不在本轮修改。

F0需要处理的实质问题：

1. v4玩法方案D01～D07仍未全部转为已实现：分别列出待决、已批未做和已有证据，不用新计划把它们一并批准。
2. 新模组禁止自然生成后的取得链要等外部交付，不临时新增配方或奖励绕开。
3. 远程职业与指定地面Boss远程免疫、剑术耗蓝与职业资源、Super-Tier特殊伤害仍存在规则接口；当前机制继续运行，重新裁决必须单列影响。
4. `pending`事件、受控入口未开放及Legendary Bosses安装状态必须逐项保留；不以新故事文案清除阻断。
5. 指南中的围城固定注册表、任务驱动计时和超时惩罚属于另一个工程的建议／记录，本轮不回写围城脚本或把它们当作已运行事实。
