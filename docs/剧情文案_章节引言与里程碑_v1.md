## 一、章节引言（16 章）

### start｜启读·出发之前（融合前：只有"你"）

```text
如果你能看到这些字，说明两件事：你醒了，而且天灾还没找到你。

这本手册教你握剑、找路、认钱、生火。它教不了你害怕——你已经会了。

先选你这一程的难度，再领桌上的东西。页边的字是我后来补的，别嫌啰嗦。

&7&o——先行者&r
```

### prologue｜序章·觉醒（融合前：只有"你"）

```text
你醒来的地方不一定安全。先学会让手里的刀听话，再谈别的。

这一章教你：姿态、连段、锁定，换一把像样的剑；然后顺着路找到人烟，攒下第一笔残魂。

最后，去找那颗陨石——从你把手伸向它的那一刻起，这本手册的后半本，只有你能看懂了。

&7&o冒险者，别嫌慢。快的人，都留在第一夜了。&r
```

### departure｜Ⅰ·启程（融合后：批注首次暗示"不只你一个"）

```text
村庄不是安全区，是防线。你在这里落脚，就在这里欠下第一笔债。

火种、竞技场、日课——这一章教你怎样把"活着"变成"过日子"。

它们每七天来一次。日历在屏幕上，红线在心里。

&7&o冒险者，睡过一觉的地方就是据点。从今天起，守它的不只你一个。&r
```

### journey｜Ⅱ·磨砺（过渡：正文仍"你"，批注首次出现"你们"）

```text
村庄外的世界，比你醒来的那片荒地大得多。

塔哨、地下、入口——先看清它们的足迹伸到哪里；再穿过那扇门，去另一轮天空下打一场完整的远征。

出门之前，先知道为什么出门：去侦察，去打穿，然后——回家。

&7&o冒险者，能走回家的，才配谈下一次出门。这句话，对你们两个都算数。&r
```

### front｜Ⅲ·天灾防线（"你们"成为常态）

```text
到这一章，别再把它们当背景。

军营、监狱、医院、实验室、大教堂——这些墙是人砌的，如今住在里面的不是人。去看清它们怎样前进、怎样繁殖、怎样把人变成它们。

路上有几位旧纪元的住客被吵醒了。它们不讲道理，但讲规矩——打赢的规矩。

&7&o冒险者，理解吞噬，才谈得上反推。去看看它们的心脏长什么样——你们一起。&r
```

### counterattack｜Ⅳ·反推（"你们"收口于终局之问）

```text
最后这一段路，手册能帮你的不多了。

两场试炼，两位只剩战斗本能的旧日英雄——打赢他们，用他们的方式。

然后是母巢。找到它，打穿它，让它们的前进停在你脚下。

最后，是最强的对手，和最后的一战。读到这里，你们应该已经很有默契了。只剩一个问题，你迟早要回答——

&6现在，是谁在主导？&r
```

> 注：末句的主语用"你"而非"你们"——回答这个问题的是玩家自己（设定§5.2：决定永远是你自己的）。

### collector｜收藏家·兵器见闻

```text
每一把兵器都记得一段旅程。这一栏不排名次，只记见闻——见过的、握过的、值得留下的。

&7&o冒险者，架子上的东西越多，你越知道自己是谁。&r
```

### smith｜锻造师·炉火与刀

```text
炉子不挑人。神兵靠奇遇，保底靠手艺——这一栏教你从第一块焦黑砖，走到最难熔的金属。

&7&o冒险者，慢慢攒出的刀，同样能陪你走远。这话我用命验证过。&r
```

### dragon｜狩龙人·与龙同行

```text
没有人见过被感染的龙——它们似乎不在天灾的食谱上，是这片天空下最自由的活物。

选一只伙伴，走完一次相遇、照料、并肩与告别。驯服是承诺，不是收集。

&7&o冒险者，它认下的是你，不是一张收集表。&r
```

### symbiote｜共生使·共同生长

```text
这一栏没有作业，只有相处。

附着、整合、合作、主导——你和它的关系走到哪一步，只有你们自己知道。

&7&o冒险者，力量在这里，决定仍在你手中。&r
```

### expedition｜可选·远征与备战

```text
主线之外的路。补给、装备、整备——不是必做，是让你下一场打得更像样。

&7&o冒险者，准备永远不算浪费。&r
```

### hunts｜可选·灾变与猎人

```text
旧纪元还醒着的几位，都在这一栏。不是必打，是值得一打。

打赢的规矩，你自己去领会。
```

### souls｜可选·魂系讨伐

```text
召唤券能请回来的，都是不肯安息的名字。

额外的挑战由你自己选择——他们不赶时间。
```

### commissions｜委托·日课与悬赏

```text
流亡者的日子靠两件事维持：日课让人不生锈，悬赏让防线轻一点。

需要准备时，就来这里挑一件事。
```

### manual｜手册·战斗与成长

```text
这一章是我自己留下的笔记：剑术、能力、规则。没有作业，随时回来翻。

&7&o——先行者&r
```

```text
路标不替你走路，但能替你记路。
```

## 二、五里程碑剧情

### A10 共生【里程碑】（prologue｜听见陨石的低语｜wired）

正文（节点描述用）：

```text
陨石坑里躺着的东西一直在等。它不要你的钱，不要你的命，只要你伸手。

融合完成的那一刻，你血管里多了一个心跳。

天灾靠抢夺身体前进，你靠分享身体变强——记住这个区别，&6它是你全部胜利的起点&r。
```

讲评（tellraw，替换候选）：`冒险者，它选了你。喂它、听它、别惯着它——这不是力量，这是关系。`

> 现有讲评"冒险者，从现在起，你不再独自成长。"可保留为前半句，与新句二选一或串联。
> 称呼说明：此处用"它选了你"而非"你们"——这是它选择你的瞬间，转折从这一刻开始（设定§5.2）。

```text
塔哨、地下、门、另一轮天空、三圣、墓穴、领主——你把一次远征的每个动作都做完整了。
```

```text
军营、病房、实验室、大教堂。你亲眼看完了它们怎样吃掉一个文明。

三场硬仗打下来，你们之间已经不需要语言。

从明天起，这本手册的读者和作者换个位置——防线之后发生的事，&6轮到你来写了&r。
```

讲评（保留现有）：`冒险者，下一次远征将以反攻为目标。`

### E12 母巢陷落【里程碑】（counterattack｜pending）

正文：

```text
你数着它们来，也数着它们倒下。最后倒下的那一个，是它们在这片土地上的心脏。

母巢陷落的意义不是"它们没了"——它们永远还会有。

意义是：从今天起，&6前进的方向反过来了&r。
```

讲评（保留现有）：`冒险者，这一次，它们的前进被你们截住了。`

> 依赖标注：母巢事件规格（波数/入口/判胜）待批待实装；若三波规格获批，正文首句可改为"三波。你数着它们来，也数着它们倒下。"

### E18 反推成功【结局】（counterattack｜pending）

```text
最后一页了。

打赢最后一战的是你的剑，是你的炉火，是村民的火种，是路上的每一步——也是住在你身体里的那位。

它让你走到了"主导"。而你读完了这本手册，应该已经知道答案：主导从来不是压制对方，是走完这一程，&6你们还认得出彼此&r。

家还在，路也还在。手册合上了，冒险者——后面的页码，归你写。

&7&o——先行者&r
```
