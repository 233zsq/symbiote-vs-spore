### 2.2 从挥刀到刀光的链条

**EF 播放攻击动画 → 取 Tool_R / Tool_L 骨骼位置 → 按武器配置取刀刃两端 → 在动画指定时间段采样轨迹 → 插值形成带状面 → 套贴图、颜色和寿命 → 由原生或自定义辉光粒子渲染。**

具体证据：

- IF 的 assets/saintsdragons/item_skins/dragonlord_sword.json：begin_pos / end_pos 决定刀刃采样端点；lifetime=6、interpolations=12；贴图 swing_trail2.png；particle_type=epicfight:swing_trail。
- IF 的 assets/epicfight/animmodels/animations/biped/combat/data/sword_airslash.json 位于 IMF-Modify：trail_effects 指定 start_time=0.0、end_time=0.1、joint=Tool_R、main_hand。
- DOTE 的部分刀光修复包中 assets/cataclysm/item_skins/the_incinerator.json：particle_type=epicacg:bloom_trail；life=5、interpolations=4；贴图 yz.png。MorePower 的 yamato_airslash 动画配置还叠了两个不同时间段的 trail_effects。
- DOTE 的 epicacg jar 确有 BloomTrailParticle 实现；SvS 已装 Nightfall 的 EFNParticles 注册了命名空间 efn 下的 **bloom_trail**，并有 BloomTrailParticle 实现。两者不能只改名字便保证视觉相同。（L4、L5）

所以，好的刀光需要**刀刃位置与模型对齐、攻击时间与动作对齐，再调贴图和透明度**。仅加粒子数量、延长残留或堆发光，很可能遮住敌人动作；这是基于上述链条的设计建议，仍以游戏录像判断。

### 3.1 重点兼容风险：证据与未证实部分分开

**WOH 会影响既有 Resurrection。** CorruptAnimationsMixin.build 开头调用 CallbackInfo.cancel，并重新写入 cdmoveset 的 CorruptAnimations 动画访问器；这与作者“内置 Resurrection 补丁”说明相符。并非仅增加七种武器。当前 svs_tweak 的 Mixin 取消名单没有取消这段 Resurrection 注册，不能虚构“已被本包屏蔽”的结论。须专项测试现有太刀/双刀/长剑处决与连招，再测 WOH 新武器。（L3；[WOH 官方页](https://www.curseforge.com/minecraft/mc-mods/epic-fight-weapons-of-harmony)）

**英雄之证改动范围最大。** mhr.mixins 涉及 ControlTravel、ControlSync、PlayerPartCollision、PlayerReaction、RidingCamera 等；HunterAnimationCompatibility 会清理部分 PlayerAnimator 变换并应用自身动画。本次找到 Better Combat / Embeddium 条件处理，但没有找到 EF 专项兼容。这是需要检验的接管风险，**不是已经复现的冲突**。HealthAttributeLimitMixin 将 generic.max_health 属性允许的上限提高至至少 **100000**；它并不是把所有生物实际血量设为 100000。其全局属性干预必须先由用户裁决，不能在原版政策待定时自动合入。（L3；[作者发行页](https://www.curseforge.com/minecraft/mc-mods/proo-of-a-hero)）

**Not So Shrimple 带第二套锻造成长。** CommonForgeEvents 给物品写入 SomberDamageBuff / SomberArmorBuff / SomberEfficiencyBuff 等 NBT，追加属性；MixinItemStack 处理 SmithingDurabilityBuff 耐久缓冲。1.1.0 默认配置上限为普通锻造石500、失色20。需决定是否接纳这套玩法及其适用装备，验证匠魂、EF 武器、交易与任务奖励关系；不在本报告直接改上限、配方或黑名单。其 crayfish_spawns 是天然刷怪 biome modifier，**不是新的地形结构**，与真正 worldgen 结构分别裁决。（L3；[官方精确版本](https://modrinth.com/mod/not-so-shrimple-remolted/version/UnGfJ0QR)）

**相机与 HUD 有实证按键问题。** 当前 options：EF 锁定 G、切换目标左/右箭头；HUD 作者默认 G 消耗物品、左/右箭头切装备。应保留用户现有 EF 习惯，对新增功能给出不冲突的按键方案，再经用户确认试用，禁止覆盖整份 options。Ambient Camera 的待机运镜、Auto Perspective 的遮挡切视角与 Leawind 需要分别验收。HUD 单机显示可客户端使用；**队友状态功能需服务器也安装**，不能一概称纯客户端功能。（L2；[HUD 说明](https://modrinth.com/mod/souls-combat-hud)）

**EF 匠魂兼容更新还触及刀光。** 20.2.10 jar 包含 AnimationTrailParticle、ItemSkinsReloadListener、TrailProvider 等 Mixin；官方变更提到黏液套装与“modifier 作为 trait、不是 upgrade”的换件修复。应独立更新，避免与刀光资源、异步粒子一起改，防止无法确定回归来源。语言键完整不能证明旧翻译已准确表达新行为。（L3；[精确版本记录](https://modrinth.com/mod/epic-fight-tinker-compat/version/sMMDwtme)）

**新 Boss 不自动继承本包 Boss 规则。** 当前地面 Boss 远程免疫按 HANDOVER §四“10-01”名单识别；新增 anka_mobs / oddities / mhr 等不在现列名单中。合入后表现须实测并提明确适配方案；不得自行扩大免疫范围、改远程结算或加数值补丁。用户此前允许“提出现装 Boss 替换方案、看样后定”，不等于批准这些新模组成为必打主线。
