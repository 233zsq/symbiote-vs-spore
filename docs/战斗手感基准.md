## 6. 格挡 / 招架

**jar 级查证（体力侧）**：举盾格挡本身不耗体力；每成功格挡一次攻击扣除 `(0.6 × 格挡叠层 + 0.6) × 攻击方 impact`——**连挡越扣越多**，天然防无限白嫖。

| 项目 | 结论 | 备注 |

## 8. 处决 / 硬直

**机制结论（jar 级查证，2026-09-10，K3；证据链见 HANDOVER 待办池#2）——本节按查证改写清单原预期：**

1. **EF 20.14 没有通用"打空韧性 → 处决"机制。** 普通怪物韧性为隐性（`stun_armor` 只缩短被眩晕时间）；**韧性条 UI 只为末影龙/数据包定制怪（`max_stun_shield > 0`）绘制，默认怪不显示韧性条是预期行为**，不是 bug 也不是配置问题。
2. **真正的处决只有两个武器固有技能**：
   - **斧类 The Guillotine**：目标血量低于本击伤害时即死斩杀，耗体力 **24**；
   - **匕首双持 Blade Rush**：连击叠加 **3 层"不稳定"** 后锁定目标释放，触发终结动画，耗体力 **25**。
3. 眩晕只播放硬直/倒地动画，倒地后**不存在"可处决"状态**；WoM 无自有处决机制。
4. "打空韧性出处决"属魂系玩家常见预期，EF 原生缺失构成设计缺口 → §11 开放项（待办池#4）。

复测项（并入阶段③ 批1 Symbiote 实测同场执行）：

| 复测项 | 操作步骤（按查证机制） | 状态 |
|---|---|---|
| 斧 The Guillotine 斩杀 | 残血怪（血量 < 本击伤害）持斧按武器固有技能键（定型 R），应即死 | 【待复测】 |
| 匕首双持 Blade Rush 终结动画 | 匕首双持连击叠 3 层"不稳定"→ 锁定目标 → 释放技能，应触发终结动画 | 【待复测】 |

大硬直（跪地/倒地）动画表现是否正常、无卡死：清单标记"？"——**待核实**（韧性条不显示已确认为预期行为）。
