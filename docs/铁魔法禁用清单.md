# 铁魔法（Iron's Spells 3.16.3）弱化 · 禁用清单【定稿 2026-09-25】

> 依据：决议一-8"只保留 buff 系+武器附魔远程系，删禁强控制/强回复"；理念 8"逃课是爽点"（机动/隐身保留）；理念 9 弱化定位。
> 用户裁决（9-25）：参考远梦之棺/终焉决斗 + 联网调研后由我定稿落地。
> 参考结论：**远梦之棺禁用一个都不用**——它走调参路线（heal 冷却 60s 等 3 条）；DOTE 无任何法术干预。本包决议要的是定位弱化，故走禁用。

## 机制（已落地）

svs 数据包 `data/irons_spellbooks/irons_spellbooks_spell_config/<spell_id>.json`，内容 `{"irons_spellbooks:enabled": false}`。
被禁法术无法施放、不出现在战利品/交易/合成；删文件即恢复，不动 mod 本体。
**当前：禁用 78 个 / 保留 36 个（全表 114）。**
