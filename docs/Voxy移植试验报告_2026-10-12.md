# Voxy 移植试验报告（2026-10-12）

> 依据用户指示：「遥远的地平线（DH）性能开销太大，想换成 Voxy；沉浸战斗整合包装了 Voxy，看它是怎么装的，是不是靠信雅互联」。全程遵「正式包不动、只在 svs_lab 试验」纪律；DH 在母本/test 保持原状。

## 〇、结论摘要

1. **沉浸战斗（IF，同为 1.20.1）装 Voxy 的方式＝信雅互联栈**：Sinytra Connector ＋ Forgified Fabric API ＋ **Fabric 版 Voxy（1.20.1 第三方移植构建）**，跑在 Forge 上。其更新日志可佐证（多次调整 Connector 版本修崩溃、有「voxy 兼容 java17」条目）。官方 Voxy 为 ARR 且**无 1.20.1 版本**，IF 用的同样是第三方移植。
2. **试验 A（实验室）加载级成功**：svs_lab 226 jar、jdk-21 启动，Voxy 经 Connector 装载、进世界（`WORLD_LOAD_FINISHED`），无崩溃；但与正式包换装存在**两个硬约束**（Java 21 捆绑、ARR/alpha 移植边界），**是否换装请用户裁决**（§五）。
3. 代价实测：启动耗时约 285s → 约 517s（+4 分钟）；启动期有卡顿告警。Voxy 的**画面效果（LOD 实景）未验证**——属实机看样范畴。

### 3.1 用户实跑发现：Canary 调色板冲突（2026-10-13）

用户实机游玩后，Voxy Ingest 服务持续抛 `java.lang.IllegalStateException: Unknown palette type: com.abdelaziz.canary.common.world.chunk.CanaryHashPalette`（栈：`WorldConversionFactory.setupLocalPalette`），累计 **7.2 万次**、latest.log 膨胀至 **69MB**、游戏内聊天刷屏。

- **根因**：Canary（Lithium 系优化，母本/test/lab 均在包，`canary-mc1.20.1-0.3.3`）用自研 `CanaryHashPalette` 替换了原版区块调色板实现；Voxy 的区块→LOD 摄取只识别原版调色板类型 → **所有区块摄取失败，Voxy 实际生成不出 LOD**（远景空白）。此前"加载级通过"未能暴露此问题——**印证加载级验证 ≠ 功能可用**。
- **处置（lab）**：`config/canary.properties` 增 `mixin.chunk.palette=false`。**键名规则实证**：Canary 的开关按**优化组名**（jar 内 116 项选项清单实证，如 `chunk.palette`），首试的类全名键被拒（日志原文：`No configuration key exists with name 'mixin.chunk.palette.PalettedContainerMixin', ignoring`）。
- **复验通过（2026-10-13 18:54 局）**：`Loaded configuration file for Canary: 116 options available, 1 override(s) found`；`chunk.palette.PalettedContainerMixin` 未应用（debug.log 0 条）；`Unknown palette` **0 次**、Voxy worker 异常 **0 次**（对照未修复局：7.2 万次）；**voxy 存储 RocksDB 活跃写盘**（18:57–18:59 新增 21MB+，此前失败局仅有空壳）——LOD 摄取管线实际启动。用户目视确认不再刷屏。
- **正式换装连带项**：生产包若采纳 Voxy，此行须同步进正式配置；或重新评估「移出 Canary × 保留调色板优化」的取舍。

## 七、原生 Forge voxy 尝试与 voxyseedgen 结论（2026-10-15）

用户问「VoxySeedGen 怎么装」——考证与实测：

- **voxyseedgen 0.3.0 的正确前置**：voxy **0.2.15+**（其 mixin 打在新版 voxy 内部结构上）＋（1.20.1 Forge 语境下）**KNaiFen/voxy 原生 Forge 0.2.15-beta**（github.com/KNaiFen/voxy releases，Java21＋Embeddium 0.3.31、自带中文界面、不需要信雅互联；已下载并 SHA256 校验）。用法：自动运行或 `/voxyseedgen fill [半径] [线程]`；**仅单机/自建局域网可用；未探索区地下为实心石头（无洞无矿）**。
- **实测结论（lab 沙箱）：与光影硬冲突**。换入「原生 voxy 0.2.15＋voxyseedgen」后，**只要加载任意光影包（Bliss）即启动 FATAL 崩溃**——crash 报告实证：`Iris.loadShaderpack → ShaderPack.<init> → client.voxy.mixins.json:iris.MixinProgramSet 注入失败`（voxy 的 Iris 兼容层按新版 Iris 编写，与 1.20.1 的 Oculus 1.8.0 不匹配）。
- ⇒ **seedgen 与「光影＋PBR（Oculus/Bliss/SPBR）」在本包互斥，二选一**；理论路线 C＝用 MixinSquared（包内已有）取消 voxy 的 iris 兼容 mixin 强行共存（未验证；shader×voxy 协作层失效，画面兼容风险自负）。
- **现状（安全态）**：三实例全部回滚为既有「DistantWorld 0.2.14 移植＋信雅互联」栈——test 226／母本 225／lab 230（**未同步任何改动**）；seedgen 与原生 voxy jar 备于 `dl/voxy_forge` 与 `hold_batch8`。待用户裁决：保光影弃 seedgen（推荐）／弃光影装 seedgen（无光影路径预期可行、需实测）／试路线 C。
- **2026-10-15 裁决与收尾**：用户**选 A（保光影、弃 seedgen）**。另用户当日曾**自行试装 Fabric 版 seedgen**（被信雅互联接走转译至 `test/mods/.connector/`）——**进世界即崩**（17:04:37 崩溃报告在案：`VoxyRenderSystem.<init>` 处 mixin 变换 `ClassCastException: ArrayList→AnnotationNode`；与前述版本不匹配结论文互为印证，无论 Fabric/Forge 版 seedgen 都需要 voxy 0.2.15+）。用户已自行撤掉顶层 jar；执行侧清理 `.connector` 缓存残渣（仅删 seedgen 两条，voxy 自身缓存保留）并复验。**结论闭环：光影路线保留；seedgen 弃置（jar 留档 hold_batch8）。**
