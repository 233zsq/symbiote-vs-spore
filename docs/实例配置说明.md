## 二、改动落点与验证层级

| 对象 | 本包落点 | 生效/验收 |
|---|---|---|
| KubeJS注册/Forge总线监听 | `kubejs/startup_scripts/` | 完整重启；确认注册/事件实际触发；Forge监听整体try/catch |
| KubeJS配方、标签、轮询桥 | `kubejs/server_scripts/` | 按脚本类型重载或重启；标签注册走ServerEvents.tags；检查错误和实际行为 |
| 数据包覆盖 | `config/openloader/data/svs/data/`及已存在的数据包目录 | 重载/启动后检查资源加载与目标行为；**kubejs/data在本机不是数据包** |
| 汉化与客户端资源 | `config/openloader/resources/` | 资源重载/重启后检查玩家可见文本、占位符和来源；见汉化维护 |
| CraftTweaker阶段配方 | `scripts/stages.zs` | 查看CrT日志，并实际尝试批准范围内配方；阶段ID方案仍待批 |
| FTB任务 | `config/ftbquests/quests/` | **只由用户游戏编辑器生成/修改SNBT**；AI只读真实ID、写设计稿和桥 |
| 自研修复 | `svs_tweak/`源码 → 母本/test的jar | 构建与manifest核对；Mixin命中证据看debug.log，latest.log不足 |
| 普通mod配置 | 实例config/或存档serverconfig/，以该mod实际声明为准 | 不能将defaultconfigs当作强制更新旧世界；核实际读取文件和游戏行为 |
| 默认键位 | `config/defaultoptions/keybindings.txt` | 面向新安装；不覆盖玩家改键；Controlling核实际注册键 |

加载无错只证明加载；功能通过须有行为实测。具体Rhino/API边界集中维护于HANDOVER五，本文不复制一套候选调用。来源：HANDOVER二.2、五.1～10；任务线框架一.2、四。
