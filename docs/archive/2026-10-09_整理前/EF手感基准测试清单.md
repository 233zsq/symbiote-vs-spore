## 附：实例与仓库同步备忘（2026-09-10 踩坑记录）

1. **packwiz-installer 必须经 bootstrap 启动**：`packwiz-installer.jar` 直接跑会弹窗报 "must be run through packwiz-installer-bootstrap"，GUI 弹窗而非控制台报错。正确姿势：`java -jar packwiz-installer-bootstrap.jar <pack.toml 的 URL 或路径>`（bootstrap 会自动更新并调起 installer）。
2. **Java 下载走 HTTP/2 会被本机代理掐断**（okhttp EOFException；curl 大文件 GET 同样断，仅 HEAD 成功）。`--http1.1` 后恢复。因此当前同步采用**手工放置**：curl --http1.1 下载 jar → sha512 比对 `.pw.toml` 的 hash → 放入实例 `mods/`。后续模组批次多时，要么修 Java 侧代理，要么评估 PCL 导入 mrpack 导出件的流程。
3. 本地起包服务：`packwiz serve --port 8520`（仓库根执行），installer 用 `http://localhost:8520/pack.toml`。
4. 实例目录：`D:\mcmp_test\versions\1.20.1-Forge_47.4.23\`（版本隔离已开）。**模组只能经仓库 packwiz 流程进实例**——PCL 的 Mod 管理界面禁用。
