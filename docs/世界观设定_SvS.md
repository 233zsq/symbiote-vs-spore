## 一、一句话世界观

天灾从天而降，把世界变成它的培养皿；而你从另一颗流星里，得到了活下去的第二种方式。

## 二、纪元简史（四段，供一切文案引用）

**旧纪元。** 这片土地上曾有过强者林立的时代：工厂里的战争机器、竞技场中的不败者、冰牢里的诅咒、高塔上的守望、猎杀兽化者的猎人、以及只留下剑与名字的英雄们。他们未必相识，也从未联手；他们共同的结局，是被自己的时代留在原地。

**陨星之夜。** 某一个夜晚，天上掉下来的东西开始改变地上的活物。它不靠撕咬那么慢的方式传播——肉丘落地，菌毯铺开，跳蚤把种子带去更远的地方。被感染的不是尸体，是还在走动的、曾经是人形的东西。村庄一座座失联，道路一段段荒芜。

**流亡纪元。** 幸存的人退守村庄，用还能走的路彼此连接。他们学会三件事：把残魂当钱使，把村民当火种护，把每七天一轮的围城当日子过。竞技场不是娱乐，是流亡者让自己不生锈的方式。

**现在。** 你醒来的时代。离你出生点不远的环带上，落着另一颗流星。它不是天灾——或者，不只是。

## 三、主题脊柱：共生 vs 吞噬

两种"进入身体"的方式，贯穿全部主线：

| | 吞噬（真菌/天灾） | 共生（共生体/伙伴） |
|---|---|---|
| 意愿 | 不问 | 要你伸手同意 |
| 方向 | 抹除自我，变成它们 | 保留彼此，共同生长 |
| 关系 | 感染、扩散、占领 | 喂养、信赖、四阶演进 |
| 代价 | 村庄、文明、名字 | 压力、失控、天敌仇恨 |
| 终点 | 母巢 | 主导（DOMINANT）——谁在主导？ |

写法要领：
- 真菌永远用**复数**称呼："天灾""它们"——它是群体，没有单个的"它"。
- 共生体永远用**单数**："它""伙伴""住在你身体里的那位"——它是具体的一个，有菌株、有性情。
- 主线情感曲线：序章"接受它"→ Ⅰ"学会共处"→ Ⅱ"并肩远征"→ Ⅲ"默契无言"→ Ⅳ回答"谁在主导"。
- 终局的答案（E18 口径）：**主导不是压制对方，是走完这一程，你们还认得出彼此。**
- 美学基调（借《湮灭》/《星之彩》）：天灾不写成"邪恶军团"，写成**美丽、繁茂、不问意愿的改变**——菌毯可以好看，这才瘆人。

## 五、手册与"先行者"设定（口吻规范）

**任务书本体 = 一位前辈冒险者留下的战地手册。** 署名"先行者"（可改）；他/她经历过陨星之夜，是最早一批融合共生体并活到"主导"的人。最终去向留白，结局节点回收（见 E18 文案）。

### 5.1 两种文体

- **正文体**（教学目标/作业/提示）：务实、冷静、简短。像手册印刷体——讲机制、给方位、标风险，不抒情。
  例："沿石板路走，你会找到村庄。先找床，再认工作站。"
- **批注体**（讲评，及引言中的批注段落）：手册页边的手写批注，是先行者本人后来补的话。可以更私人、更冷幽默、更有压迫感。统一以"冒险者"开头或落脚。
  例："冒险者，钱能换料，料能换命。这条链你今天走通了第一步。"

### 5.2 称呼渐变（v2 采纳）："你"→"你们"

称呼本身就是关系弧的进度条，全书按下表执行：

| 范围 | 口径 |
|---|---|
| 序章及以前（融合前） | 一律"你"；共生体尚未进场 |
| A10【共生】 | 转折点："它选了你"——仍是"你"，因为这是它选择你的瞬间 |
| Ⅰ启程／Ⅱ磨砺 | 正文仍用"你"；批注中首次出现、至多每章一处"你们"或暗示（"不只你一个"） |
| Ⅲ天灾防线／Ⅳ反推 | 批注以"你们"为常态；"你们之间不需要语言"这类写法允许 |
| E18 结局 | 收口于"你们"："走完这一程，你们还认得出彼此" |

注意区分：涉及玩家个人抉择/所有权的场合（菌株、终局选择、"决定仍在你手中"）始终用"你"——**关系是共同的，决定是你自己的**。

### 5.3 色码纪律（v2 采纳）

FTB 文本支持 `&` 色码。全包只用这四种语义，其余一律无色（默认白）：

| 色码 | 语义 | 用法 |
|---|---|---|
| `&7&o`（灰斜体） | 先行者批注 | 引言批注段、讲评氛围句 |
| `&6`（金） | 里程碑关键词/称号 | 每个里程碑至多一处关键词；日常节点不用 |
| `&4`（暗红） | 风险与失守 | 死亡惩罚、失守、失控等真正的坏消息 |
| `&5`（暗紫） | 天灾侧词汇 | 仅"母巢""肉丘"等核心名词首次出现时可选；宁少勿多 |

纪律：强调色全文档克制使用（色码滥用是 CTI 的反面教材）；每段着色后补 `&r` 复位；**色码需经 build 透传与游戏内渲染双重确认后放量**（首批先在章节引言与里程碑验证）。

### 5.4 口吻纪律

- 称呼玩家一律"冒险者"，不用"你"以外的第二人称混用（正文体内"你"可用，讲评以"冒险者"为标志）。
- 先行者不知道未来的细节：不写"你将遇到 XX Boss 的第几阶段"，只写"我活到了那一战，愿你也是"。
- 先行者可犯错、可留白：标注"这段我看不清""别学我"是允许的姿态，增强真实感。
- 不搞元反转（不否定玩家的旅程），不玩热梗；冷幽默允许，密度从严。
- 死亡要直视（类魂口径）："怕死的人活不久"可以说，"没关系下次一定"不可以说。

### 5.5 奖励物品名与 lore 参与叙事（v2 采纳）

- 四职业毕业饰品（改名"XX之记"为已批方向）各配**一行** lore；E17 毕业武器三选一配一行通用 lore。文案见《剧情文案_章节引言与里程碑》§三。
- lore 只写氛围，不写数值、不写获取方式、不承诺效果；实装路径（KubeJS tooltip/改名 NBT）另行批准后执行，不改物品属性。

## 七、禁写清单

1. 不虚构模组物品、机制、因果（如"共生体是某人制造的""母巢在呼唤你"——母巢无自我意识设定）。
2. 不声称各 mod 官方同源；映射表内容只是本包编排。
3. 不承诺未实装内容为事实：触手辅助战（分期 2）、NG+、母巢具体波数与配置、随机券池——留白或标"尚未开放"。
4. 未看样的 Boss 不写招式/阶段描写；未批准的名单不写死：终局＝被诅咒者与斯库拉待选（文案用"最后的对手"口径占位）；Ⅲ三代表战、SLU 两试炼人选待批。
5. 不写固定坐标与方向承诺（"东北方""紫光柱"已证伪）；只写"只给方位不给坐标"。
6. SLU 专名译名未逐个对照评审前，正文不首次启用新译名。
7. 排行氛围化：不写数值 Tier、不写"最强/最弱"。
8. 不让先行者预言玩家的具体选择（难度、职业、菌株、终局人选均由玩家定）。
9. 不写"全球真菌已被清除""世界恢复和平"——结局口径是"家还在，路也还在"。
10. 不搞元反转、不玩热梗、不堆砌无因果的世界观名词（四包拆解的共同教训）。
