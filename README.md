# Symbiote vs Spore · 共生体 vs 真菌

Minecraft 1.20.1 Forge 动作冒险整合包。以 Epic Fight 为战斗底座，在体内养成共生体，在体外抵抗 Spore 真菌侵袭：建立军工要塞、掠夺诸王力量，走向母巢总攻与齐天终章。

**项目仍在制作中。仓库任务源为v6.1；六个新模组与两个前置已于2026-10-31安装到母本和test，Spawn暂未启用。剧情与FTB后续按F0—F4计划推进，游戏验收由用户负责。** 见[文档入口](docs/README.md)、[本批入包记录](docs/模组9_入包与回退记录_2026-10-31.md)和[剧情／FTB施工计划](docs/剧情与FTB施工计划_2026-10-31.md)。

## 想做怎样的冒险

- **动作先于数值。** Boss 选型优先看模型与动作，再看特效、技能和完整战斗流程，最后调整数值；主线24场核心Boss按阶段组织，另设24席独立讨伐。
- **旅程有前因后果。** 主线四阶段为Ⅰ血肉筑基、Ⅱ疆域割据、Ⅲ劫火与神权、Ⅳ天基总攻与齐天终章；序章负责降临、融合与立旗。备战、寻找入口、交战、使用战利品和归乡共同组成一次远征。
- **成长有多种路线。** 收藏家、锻造师、狩龙人、共生使四条职业支线并行，没有转职互斥，也不要求四职业全部毕业才能结局。
- **查资料与推进分开。** 手册随时可查；主线、职业、可选讨伐、循环委托分别组织。任务书说明实际取得方法和检测条件，不把读完说明当作击败 Boss。

剧情与名单见[天外成王篇v4](docs/剧情重写_v4_天外成王篇.md)及[四传说v5增补](docs/剧情重写_v5_旧世四传说与造界者.md)。大圣残躯为两阶段最终试炼；四个Legendary Bosses关口已在仓库规划，模组仍待单独安装和验收。任务页对尚未实现的入口、军工与事件保留开放状态提示。

## 仓库里有什么

```text
config/        配置、OpenLoader 数据覆盖、FTB 任务
kubejs/        物品、配方、交易、围城与任务桥等脚本
scripts/       CraftTweaker 阶段配方锁
svs_tweak/     自研兼容与修复模组源码
mods/          packwiz 模组元数据（不包含全部 jar）
tools/         检查、采样、标签与任务生成工具
docs/          当前规格、实证资料、执行状态与历史档案
```

仓库保存制作源码和元数据。**克隆仓库不等于取得一份已验证、可直接启动的完整整合包**；完整实例与发布包应核对实际 jar、配置和覆盖文件。硬件最低要求、当前版本性能及发行下载方式尚未形成可承诺的验收结果。
