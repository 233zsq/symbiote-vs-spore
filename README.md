# Symbiote vs Spore · 共生体 vs 真菌

Minecraft 1.20.1 Forge 动作冒险整合包。以 Epic Fight 为战斗底座，在体内养成共生体，在体外抵抗 Spore 真菌侵袭：从村庄立足、远征与防卫，走向母巢反推。

## 想做怎样的冒险

- **动作先于数值。** Boss 选型优先看模型与动作，再看特效、技能和完整战斗流程，最后调整数值；每阶段少数必打，其余作为可选讨伐。
- **旅程有前因后果。** 主线四阶段为Ⅰ启程、Ⅱ磨砺、Ⅲ天灾防线、Ⅳ反推；序章负责入门。备战、寻找入口、交战、使用战利品和归乡共同组成一次远征。
- **成长有多种路线。** 收藏家、锻造师、狩龙人、共生使四条职业支线并行，没有转职互斥，也不要求四职业全部毕业才能结局。
- **查资料与推进分开。** 手册随时可查；主线、职业、可选讨伐、循环委托分别组织。任务书说明实际取得方法和检测条件，不把读完说明当作击败 Boss。

这是已批设计方向，具体 Boss 名单及尚未实现的事件另有状态标注。终局先比较被诅咒者与斯库拉，尚未定选；SLU 薪王化身已排除为终局。依据：[框架](docs/任务线框架规格书_v1.md) §〇～三、[待裁决清单](docs/待裁决清单.md)、[Boss 研究](docs/主线深化研究_全模组与战斗筛选.md)。

## 仓库里有什么

```text
config/        配置、OpenLoader 数据覆盖、FTB 任务
kubejs/        物品、配方、交易、围城与任务桥等脚本
scripts/       CraftTweaker 阶段配方锁
svs_tweak/     自研兼容与修复模组源码
mods/          packwiz 模组元数据（不包含全部 jar）
tools/         检查、采样、标签与任务生成工具
docs/          当前规格、实证资料、执行状态与历史档案
```

仓库保存制作源码和元数据。**克隆仓库不等于取得一份已验证、可直接启动的完整整合包**；完整实例与发布包应核对实际 jar、配置和覆盖文件。硬件最低要求、当前版本性能及发行下载方式尚未形成可承诺的验收结果。
